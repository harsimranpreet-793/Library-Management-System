# Library Management System

## About the Project
A Library Management System developed using C# and .NET with SQLite.

## Technologies Used
- C#
- .NET
- SQLite

## Features
- Add Books
- View Books
- Book Record Management

## Objective
To simplify library record management and reduce manual paperwork.

## Future Enhancements
- Search, Update and Delete Books
- Student Login
- Book Issue and Return
- Fine Calculation
- Online Deployment
